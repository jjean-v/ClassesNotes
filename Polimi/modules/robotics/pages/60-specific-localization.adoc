### Discrete Time Kalman Filter 

computing the position as a linear equation of the last position and the velocity*times

* A~t~(n x n) describes how state evolves from t-1 to t w/o controls or noise
* B~t~(n x l) describes how control ut changes the state from t-1 to t
* C~t~(k x n) describes how to map the state x~t~ to an observation z~t~
* random variables representing process and measurement noise assumed independent and normally distributed with covariance R~t~ and Q~t~ respectively
