= Linear Regression


## What is Regression ?

* Learn an **approximation** of function f(x) that maps an inputs __x__ to a continuous output __t__  from a dataset __D__
[stem]
++++
D = \{(x, t)\} \Rightarrow t = f(x)
++++

* How do we model __f__ ?
* How do we evaluate our approximation ?
* How do we optimize our approximation ?


## Linear Regression

In linear regression stem:[\mathcal{D} = \{(x, t)\} \Rightarrow t = f(x)] is modeled with **linear functions**

* Linear models can be easily **explained**
* A linear regression problem can be solved **anatically**
* Linear functions can be extended to model also **non-linear relationships**
* More sophisticated methods are based on linear regression

### Model

The simplest linear model can be defined as 

[stem]
++++
y(\mathbf{x}, \mathbf{w}) = w_0 + \sum_{j=1}^{D-1} w_j x_j = \mathbf{w}^T \mathbf{x}
++++


### Loss funtions and optimization

A convenient **error loss function** is the **sum of squared erros (SSE)**

## Linear Model and Basis Functions

### Linear Models

* A linear combination of the input variables is not enough to model data...
* ... but we just need a regression model that is **linear in the parameters**
* We can define a model using non-linear **basis functions**

[stem]
++++
y(\mathbf{x}, \mathbf{w}) = w_0 + \sum_{j=1}^{M-1} w_j \phi_j(\mathbf{x})
++++

[stem]
++++
y(\mathbf{x}, \mathbf{w}) = \mathbf{w}^T \boldsymbol{\phi}(\mathbf{x})
++++

With

[stem]
++++
\boldsymbol{\phi}(\mathbf{x}) = \left(1, \phi_1(\mathbf{x}), \ldots, \phi_{M-1}(\mathbf{x})\right)^T
++++

[stem]
++++
\mathbf{w} = \left(w_0, w_1, \ldots, w_{M-1}\right)^T
++++

## Regularization


* How do we extend the loss function ?

    L(w) = L~D~(w) + lambda * L~W~(w)

    *  L~D~(w) is the usual loss function
    * L~W~(w) account for model complexity
    * lambda is the **regularization** coefficient

## Least Squares and Maximum Likelihood

### Maximum Likelihood

* We can deal with regression in a probabilistic way
** We define a probabilistic model that maps inputs (𝑥) to outputs (𝑡)
** Such probabilisic model, 𝑓(𝑥, 𝑤), will include some unknown parameters 𝑤
** Then, we model the likelihood, i.e., the probability that observed data 𝒟 is generated by a given set of parameters 𝑤 :

    __p__(__D__|w)

** Finally, we can estimate **parameters** (w) by maximizing the likelihood:

    w~ML~ = arg max __p__(__D__|w)
